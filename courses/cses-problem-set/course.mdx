# CSES Problem Set — DSA Interview Grind

The full [CSES problem set](https://cses.fi/problemset/) — a canonical hunting
ground for competitive-programming and placement interviews — turned into a
structured course. Each problem is one lesson teaching the **algorithm** behind
it, not just the answer.

## Every lesson follows the same pack
1. **Theory** — the technique/algorithm: what it is, when to reach for it, why
   it works, complexity.
2. **Question** — the problem statement, constraints, I/O format, and the CSES
   sample test.
3. **Solution** — a real, runnable C++ `solve()` (in the sandbox).
4. **Code logic** — why that algorithm maps to THIS problem.
5. **Walkthrough** — a traced run: sample input → expected → actual.

1. Introductory Problems (24)
2. Sorting and Searching (35)

6. Tree Algorithms (16)

9. Geometry (16)
10. Advanced Techniques (25)
11. Sliding Window Problems (11)
12. Interactive Problems (6)
13. Bitwise Operations (11)
14. Construction Problems (8)
15. Advanced Graph Problems (28)

Lessons are numbered continuously; each carries a `section` tag so the roadmap
shows the CSES chapter.
