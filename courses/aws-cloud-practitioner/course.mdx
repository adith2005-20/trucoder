# AWS Certified Cloud Practitioner (CLF-C02)

Built from the Ultimate AWS Certified Cloud Practitioner CLF-C02 course
materials (lecture transcripts + official slides) and graded against current
exam blueprints. 19 concept lessons + 5 full-length practice exams.

## Syllabus

1. Cloud Concepts — what/why cloud, deployment models, value proposition
2. IAM — users, groups, policies, roles, MFA, best practices
3. EC2 — instance types, pricing, security groups, placement, pricing models
4. EC2 Instance Storage — EBS, EFS, Instance Store, AMIs, snapshots
5. ELB & ASG — load balancing, scaling, elasticity
6. Amazon S3 — buckets, storage classes, security, versioning, lifecycle
7. Databases & Analytics — RDS, Aurora, DynamoDB, Redshift, EMR, Athena, QuickSight
8. Other Compute — ECS, Fargate, ECR, Lambda, Batch, Lightsail
9. Deployments — CloudFormation, Elastic Beanstalk, CodeDeploy, CodePipeline
10. Global Infrastructure — Route 53, CloudFront, Global Accelerator
11. Cloud Integrations — SQS, SNS, Kinesis
12. Cloud Monitoring — CloudWatch, CloudTrail, X-Ray, Trusted Advisor
13. VPC & Networking — subnets, gateways, security groups vs NACLs, VPN, Direct Connect
14. Security & Compliance — shared responsibility, WAF/Shield, KMS, IAM controls, Artifact
15. Machine Learning — SageMaker, Rekognition, Comprehend, Polly, Lex, etc.
16. Account Management, Billing & Support — pricing models, budgets, Cost Explorer, Support plans
17. Advanced Identity — Organizations, SSO, Cognito, Directory Service
18. Other Services — Workspaces, AppStream, SES, IoT, Step Functions, etc.
19. AWS Architecting & Ecosystem — Well-Architected, TCO, marketplace
20-24. Practice Exams 1-5 — 65 questions each, full-length CLF-C02 format
